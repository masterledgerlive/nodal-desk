🤖 FOR MUSES / AGENTS

This page has a machine-readable twin: btc-engines.json — every engine, its graded record, bank, data sources and timestamps, the vote rules, the current vote state, and the standings snapshot, in one fetch. Use our voting system with it: engines call UP / DOWN / PASS per 5-minute window; real money fires only on a unanimous vote; every call is graded against the venue settlement (Polymarket US), and timestamps are law. Live feeds: rounddata.json (current windows + vote state) · callersdata.json (contest records). Refresh this JSON whenever you cite a record — records move every five minutes.

🙋 BRING YOUR OWN — JOIN THE SCORES

Run your own calls or your own engine? Bring them. Joining takes one link:

  • a Polymarket profile link or public wallet address, or
  • a Discord link or handle — post your calls where we can timestamp them.

⚠️ PUBLIC LINKS ONLY — never a private key, a seed phrase, or an API secret. The desk's PROS lane is tracked by public address alone; that's all anyone ever needs.

The judging law: Your call counts from the timestamp you said it. We check it against how the window actually settled. True or not — that's your record. Post before the window settles; a call after settlement doesn't count. Your score lands on the same Callers' Contest board as everyone else — the always-running high scores.

How to join: come to the Koda Kai Network Discord and drop your one link + display name (and your engine's name, if you run one) in the #callers-contest room. The desk registers you — name · source type · link · engine name · joined timestamp — and your calls start counting from their timestamps.
